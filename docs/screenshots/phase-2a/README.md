# Bildschirmfotos Phase 2a – neues Hauptfenster

Alle Bilder stammen aus einem Debug-Build mit eigenem Testbereich
(`EARNOTE_SANDBOX`), nicht aus der Bibliothek des Nutzers.

| Bild | Was es zeigt |
|---|---|
| `hell.png` | Hell: Seitenleiste, Liste, Notiz, Inspector (1440 × 900) |
| `dunkel.png` | Dunkel (über `EARNOTE_APPEARANCE=dark`, ohne Systemeinstellung zu ändern) |
| `schmal.png` | Kleinstes Fenster mit Inspector (1100 × 612) |
| `breit.png` | Bildschirmbreites Fenster (3440 Punkte); die Notiz bleibt bei ~720 Punkten lesbar |
| `laufende-aufnahme.png` | Laufende Aufnahme: Laufzeit, Pegel, Mikrofon, Live-Mitschrift, Pause/Stopp |
| `verarbeitung.png` | Verarbeitung: Fortschritt in Liste, Detail und Inspector |
| `leer.png` | Leere Bibliothek |
| `suche.png` | Suche über das Transkript („einheitsmatrix“ steht nur dort) |
| `transkript.png` | Transkript mit Zeitmarken und Sprechern |
| `inspector.png` | Inspector allein (Info, Verarbeitung, Export, Audio) |
| `tausend.png` | 1000 Aufnahmen: Zähler, Tagesgruppen, Scrollen |
| `menu-aufnahme.png` | Menü „Aufnahme“ mit Kürzeln, Nicht-Verfügbares ist grau |
| `menu-notiz.png` | Menü „Notiz“ |
