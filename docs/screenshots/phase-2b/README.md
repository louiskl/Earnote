# Bildschirmfotos Phase 2b

Alle Bilder aus einem Debug-Build mit eigenem Testbereich (`EARNOTE_SANDBOX`),
nicht aus der Bibliothek des Nutzers. Dunkel über `EARNOTE_APPEARANCE=dark`,
der Call-Hinweis über `EARNOTE_DEMO_CALL=Zoom` (beides nur in Debug-Builds).

| Datei | Was es zeigt |
|---|---|
| `bereich-a-hell.png` | Hell, Bereich „1:1-Gespräch“ gewählt: getönte Symbole in der Seitenleiste |
| `bereich-dunkel.png` | Dunkel, Bereich gewählt, Verarbeitung läuft |
| `buehne-hell.png` | Aufnahme-Bühne hell: Status, Laufzeit, Wellenform, Pause/Stopp, Quelle |
| `buehne-dunkel.png` | Aufnahme-Bühne dunkel, dazu ein sehr langer Bereichsname (wird gekürzt) |
| `buehne.mp4` | 7 Sekunden der laufenden Bühne |
| `call-banner.png` | Call-Hinweis als flache Pille, eine Zeile, ohne Umbruch |
