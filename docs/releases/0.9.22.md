### Deutsch

**Englische Oberfläche vollständig:** Rund 90 Texte erschienen auf Englisch noch auf Deutsch – Mitteilungen wie „Notizen fertig“, die Statuszeile beim ersten Start, Fehlermeldungen, Berechtigungen, Ziele und der Dialog beim Beenden. Jetzt ist alles übersetzt.

**Call-Erkennung:** Bei Calls im Browser steht jetzt schlicht „Arc-Call erkannt“ statt „Browser-Call (Arc)-Call erkannt“.

**Earnote unterstützen:** Earnote bleibt kostenlos. Wer es unterstützen möchte, findet dazu einen Link im Hilfe-Menü und unter Einstellungen › Über.

### English

**Fully English interface:** About 90 texts still showed up in German – notifications like “Notes ready”, the status line on first launch, error messages, permissions, destinations and the quit dialog. Everything is translated now.

**Call detection:** Browser calls now simply say “Arc call detected” instead of “Browser-Call (Arc) call detected”.

**Support Earnote:** Earnote stays free. If you'd like to support it, there's a link in the Help menu and under Settings › About.
